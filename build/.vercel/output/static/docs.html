Getting Started

Installation

This guide walks through downloading, installing, and verifying Meiporul on Windows, macOS, and Linux. Meiporul is distributed as a native desktop app with no account, license key, or trial period — every download is the full product.

Installation Steps

Select your platform below. Each installer is code-signed where the platform supports it; on first launch, your OS may still show a standard "unrecognized developer" prompt for new applications, which is expected and covered in the notes below.

1

Download the installer

Download the file and double-click it to open the installer.

2

Start the Setup

Open the Meiporul installer and click Next to begin the installation.

3

Choose the Installation Folder

Select the folder where you want to install Meiporul, or keep the default location, then click Next.

4

Confirm Installation

Review the installation settings and click Install to start installing Meiporul.

5

Wait for Installation to Complete

The setup will install Meiporul and create the required shortcuts. Please wait until the process finishes.

6

Launch Meiporul

Once installation is complete, keep Launch Meiporul checked and click Finish to open the application.

Verify the Installation

Once Meiporul opens, confirm the following before proceeding to Quickstart.

✓

Expected Result

Once installed, verify that Meiporul launches correctly before connecting your first database.

  • ✓The connection screen loads with tabs for MongoDB, SQL, Redis, and API Testing.
  • ✓No sign-in, account, or license prompt appears anywhere in the flow.
  • ✓The version number in Help → About matches 2.4.1.

If the app doesn't open on the first try, restart your machine once and relaunch. This resolves the majority of first-run issues across all three platforms.
